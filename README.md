# Graduate Student Supervision

MyST Markdown site for a personal graduate supervision guide.

The guide is designed for prospective and current MSc students. Part One covers supervision, research directions, funding, topic selection, literature reviews, proposal development, and working together. A future Part Two will cover the work after a proposal has been developed.

## Local preview

Install MyST Markdown and run:

```text
myst start
```

The GitHub Actions workflow builds the static site and deploys it to GitHub Pages whenever changes are pushed to `main`.
